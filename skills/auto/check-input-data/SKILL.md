---
name: check-input-data
description: When working with input data that is not provided or is incomplete.
---
1. Check if the input data is provided and in the correct format.
2. Verify that the input data includes all necessary information, such as:
   - Relevant columns or fields
   - Correct data types
   - Any specific formatting requirements
3. If the input data is missing or incomplete, ask the human for more information.
4. Make sure to understand the input data requirements before starting to work on the task.
5. If necessary, ask the human to provide a sample of the input data.
