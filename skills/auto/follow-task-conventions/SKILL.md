---
name: follow-task-conventions
description: When working on a task that requires following specific conventions.
---
1. Read the task description and look for any specific conventions or requirements.
2. Check if the task description includes any references to external resources, such as:
   - Documentation or guidelines
   - Code style guides
   - Data formatting requirements
3. Make sure to follow the specified conventions and requirements.
4. If you are unsure about any convention or requirement, ask the human for clarification.
5. Double-check your work to ensure that it meets all the specified conventions and requirements.
