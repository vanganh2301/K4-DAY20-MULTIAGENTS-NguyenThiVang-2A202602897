---
name: validate-task-description
description: When the task description is unclear or incomplete.
---
1. Read the task description carefully and ask for clarification if needed.
2. Identify the main objective of the task and the expected output.
3. Check if the task description includes all necessary information, such as:
   - Input data and files
   - Expected output format
   - Any specific requirements or constraints
4. If the task description is incomplete or unclear, ask the human for more information.
5. Make sure to understand the task requirements before starting to work on it.
